Local data controls / 기기 데이터 삭제

Data on this device

HearAssist has no user account or app server. The publisher cannot retrieve or delete your microphone audio or settings remotely. No microphone recording files are created.

  1. Reset sound controls to restore their default values. This does not erase microphone permission-request history.
  2. While stopped, open Settings → Privacy policy / app information → Delete latest trial numbers to remove the optional latest numeric 8-second trial receipt.
  3. To remove all internal settings, numeric receipt and permission-request history, use Android Settings → Apps → HearAssist → Storage → Clear data, or uninstall HearAssist.

Deleting app data does not delete messages you sent by email or development evidence copied separately to a PC. Contact db0192a@gmail.com about support-email deletion. Reopening or reconnecting does not start a session.

이 기기에 저장된 데이터

HearAssist 계정·앱 서버는 없습니다. 게시자가 마이크 원음이나 설정을 원격 조회·삭제하는 기능도 없습니다. 마이크 녹음 파일은 생성하지 않습니다.

  1. 소리 조절 초기화는 기본 조절값을 복원합니다. 마이크 권한 요청 이력은 지우지 않습니다.
  2. 정지 상태에서 설정 → 개인정보처리방침 · 앱 정보 → 최근 시험 수치 삭제를 누르면 선택적으로 저장한 최근 8초 시험 수치를 지웁니다.
  3. 설정·수치 기록·권한 요청 이력을 모두 지우려면 Android 설정 → 앱 → HearAssist → 저장공간 → 데이터 삭제를 사용하거나 앱을 삭제하세요.

앱 데이터 삭제는 별도로 보낸 이메일이나 PC에 복사한 개발 증거를 지우지 않습니다. 문의 이메일 삭제는 db0192a@gmail.com으로 요청하세요. 앱 재실행이나 이어폰 재연결로 세션이 시작되지 않습니다.
