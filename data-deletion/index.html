Local data controls / 기기 데이터 삭제

There is no HearAssist account or server data. Settings stay in the app on your device. Reset controls restores defaults. Android Settings → Apps → HearAssist → Storage → Clear data, or uninstalling the app, deletes internal app data. Reopening requires a new listening confirmation.

HearAssist 계정·서버 데이터는 없습니다. 설정은 기기에만 저장합니다. 설정 초기화는 기본값으로 되돌립니다. Android 설정 → 앱 → HearAssist → 저장공간 → 데이터 삭제 또는 앱 삭제로 내부 데이터를 지울 수 있습니다. 다시 열어도 새 청취 확인이 필요합니다.

The optional latest numeric 8-second trial receipt can be deleted while stopped from Privacy policy → Delete latest trial numbers. No microphone recording files are created. This does not delete development evidence previously copied to a separate PC.

선택한 최근 8초 시험 수치 기록은 정지 중 개인정보처리방침 → 최근 시험 수치 삭제에서 지울 수 있습니다. 마이크 녹음 파일은 생성하지 않습니다. 별도 PC로 복사한 개발 증거 파일은 삭제하지 않습니다.
